What this company does, for whom, and why it exists — three sentences a new coworker (human or
agent) should read first. Replace this with yours.

Start small: describe what a new coworker would need on day one. Every agent session is that
coworker. Grow the description from incidents — every time an agent gets something wrong or asks
something only you knew, a paragraph is missing here.
